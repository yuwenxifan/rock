# 洛克王国世界 · 背包截图采集统计

Vue 3 纯前端应用，用于分析《洛克王国世界》游戏材料分类页背包截图，自动识别采集物数量并计算跑图增量。

## 技术栈

- Vue 3 + Composition API
- Vite
- Pinia
- Element Plus

**图像识别**：RGB 颜色直方图 + 边缘方向直方图交叉比对。以游戏内截图作为参考图，按 `0.55 * 颜色相似度 + 0.45 * 边缘相似度` 加权打分，取最高分且与第二名的置信度差距达标才接受匹配，无需外部模型。

**OCR 数量识别**：投影分割 + 真实字符模板逐像素 Jaccard 比对。预处理流程：裁剪数量条 → 放大 → 阈值翻转 → 垂直投影分割字符 → 每个切片与 11 个模板逐像素比对取最高匹配率。仅识别 `x` + 数字格式。

## 快速开始

```bash
npm install
node scripts/generate-ref-images.js
npm run dev
```

## 功能

- 跑图前/后双阶段多图上传
- 自适应 6 列格子分割（不写死坐标）
- pHash 图像比对 + OCR 数量识别
- 同阶段校验阻断
- 花/矿、咕噜球、物品明细三维度结果
- localStorage + IndexedDB 持久化
- 调试可视化模式（格子定位、识别状态标注）
- OCR 调试详情（预处理图像 + 逐字符模板匹配，默认关闭）

## 调试

### 调试可视化模式

页面上的「调试模式」开关可开启格子定位可视化，显示每个格子的识别状态、图标区/数量条边界、角标位置等。

### 调试详情（默认隐藏）

OCR 预处理图像、遮罩预览和模板匹配详情默认关闭且不处理数据。在浏览器控制台执行以下命令启用：

```js
// 开启调试详情（OCR 预处理图、遮罩预览、模板匹配详情）
localStorage.setItem('rock_debug', '1')

// 关闭
localStorage.removeItem('rock_debug')
```

开启后刷新页面，调试模式中会额外显示：
- **OCR 预处理图像**：放大 + 二值化翻转后 OCR 实际处理的图像
- **模板匹配详情**：每个字符的分割区域、与各模板的 Jaccard 匹配得分

## 配置

编辑 `public/config/items.json` 添加物品，参考图放入 `public/config/images/`。
